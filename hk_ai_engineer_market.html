01 · Market Overview

市场概览Overview

香港的 AI 岗位需求正从「研究向」转向「交付向」：企业不再只招写论文的算法工程师，而是大量招募能把 LLM/RAG/Agent 落地到生产系统、对接业务系统的工程型人才。这与你的 4 年软件开发背景天然契合 —— 缺口不在「算法推导」，而在「工程化落地」。

🏦银行 & 金融

HSBC、渣打、星展、中银香港、富途、老虎证券等大量招聘 AI 工程人才，用于智能客服、合规审查、文档处理、投研 Copilot。薪资全港最高。

🛡️保险 & 公营

Manulife、AIA、保诚、Bowtie、Intact Lab（香港科学园）、香港生产力局等。重点是内部流程自动化、理赔智能化、RAG 知识库。

💼咨询 / IT 服务交付

Sia Partners、Accenture、Deloitte、Infosys、TCS、IBM 等。模式 = 为客户交付 AI 项目（RFP 竞标 → PoC → 生产落地），最匹配「交付向程序员」定位。

🚀初创 / 产品 & 跨国企业

WATI、Hyphen Connect 客户、Mile AI、SCMP、Bosch、Allianz、中移动国际等。GenAI 产品化、内部 AI 自动化、Agent 平台。

📌 核心结论：香港 AI 招聘市场对「会写 Python 的算法研究员」需求有限，对「能把 AI 功能可靠交付进生产环境 + 能和业务/客户沟通 + 懂云与工程化」的工程师需求强劲。你已有 4 年工程经验，只差补齐 LLM/GenAI 技术栈 与 AI 交付方法论 两块拼图。

07 · Career Path

你的成长路径：4 年 SWE → 交付向 AI 工程师Roadmap

基于香港市场真实 JD 的任职要求反推（Buyandship 要求 3 年+开发含 1 年+ Python AI；Allianz 要求 2–5 年工程 + 1–2 年 ML/GenAI；Sia Partners 要求 6 年+ 含 AI 交付）。你的工程年限已经达标，重点是补齐 AI 专项经验。

你现在：4 年软件工程师

✅ 已有：软件工程、API、数据库、CI/CD、测试、版本控制、云基础 —— 这些恰好是 AI 工程师 JD 的「硬性要求」

❌ 缺：Python AI 生态、LLM API、RAG/向量库、Agent、MLOps、AI 交付经验

第 1 阶段：AI 基础（1–2 个月）

Python AI 生态（NumPy/Pandas/scikit-learn）→ LLM API（OpenAI/Anthropic/Gemini）→ Prompt Engineering → 用 FastAPI 封装第一个 LLM 服务。

第 2 阶段：RAG + Agent（2–3 个月）

LangChain / LlamaIndex → 向量数据库（pgvector/Chroma/Milvus）→ RAG 完整链路 → Agent（tool calling、MCP）→ 参照 SCMP / Allianz JD 打造 PoC。

第 3 阶段：生产化交付（2–3 个月）

LLMOps/MLOps（评估、监控、CI/CD）→ Docker/K8s 部署 → 云 AI 服务（Azure/AWS/GCP）→ 参照 Sia Partners / Buyandship JD 打磨「生产级」能力。

目标岗位画像（6 个月后）

「中级 AI 工程师」：Python + RAG/Agent + FastAPI + Docker + 云 + 中英双语沟通，能独立把客户/业务需求交付为生产 AI 应用。对标 Allianz、SCMP、咨询公司同级别岗位。

  • Sia Partners · AI Eng Manager：6 年+ AI 交付、客户端方案设计、LangChain/PyTorch/HF、MLOps/GenAIOps、评估体系、粤语优先 —— 这是 3–5 年后的进阶目标
  • WATI · Staff AI Engineer：5 年+ 后端 + Python、多模型网关、RAG + 多 Agent（MCP）、向量库、语音 AI —— 产品向高薪路线
08 · Action Plan

90 天行动清单Actionable

每天 1–2 小时，用「项目驱动」替代「刷课驱动」—— 香港面试官最看重你能展示的交付作品。

📚第 1–30 天 · 筑基

  • Python AI 三件套：NumPy / Pandas / scikit-learn 上手（1 周）
  • 调用 OpenAI / Anthropic / Gemini API，写 5 个 Prompt 应用
  • 用 FastAPI 把 LLM 封装成 REST 服务 + 简单前端
  • 目标产出：一个可演示的 LLM 聊天/文档问答服务

🧩第 31–60 天 · RAG + Agent

  • LangChain / LlamaIndex 完整 RAG 链路（加载 → 切分 → 向量化 → 检索 → 生成）
  • 向量库：pgvector（若你会 PostgreSQL 最快上手）→ 再试 Chroma / Milvus
  • Agent 基础：function calling / tool calling、MCP
  • 目标产出：企业知识库问答机器人（含引用与评估）

🚢第 61–90 天 · 生产化 + 求职

  • Docker + 云部署（Azure / AWS，免费额度即可）
  • 加 LLM 评估（Ragas/自建评测集）、日志与监控 —— 面试必问
  • 把 3 个项目写成文档 + 上 GitHub + 录 Demo 视频
  • 投递：咨询交付岗为主（最契合），银行/保险/初创并行；准备 LLM 八股 + 系统设计
🧭 面试重点提示：香港 AI 岗位面试通常 = ①Python/算法题 ②LLM 基础（RAG 原理、Token 计算、幻觉与评估、Agent 架构）③工程系统设计（如何把 RAG 服务化、高并发、成本优化）④案例深挖（你交付过什么）。你的 4 年工程案例 + 90 天 AI 项目 = 差异化竞争力。
09 · Method

研究方法与数据来源Methodology

本报告基于 2025 年真实抓取与分析的香港招聘数据，结合公开市场薪酬信息整理。

🔬调研过程

  • 在 talent.com（聚合 jobsdb/CTgoodjobs/Indeed/各 ATS 的香港职位）用 AI Engineer / LLM Engineer / Generative AI / ML Engineer / AI Consultant / AI Developer 等关键词检索，扫描 70+ 个职位
  • 深度解析 10 份完整 JD：Buyandship、Allianz Global Investors、SCMP（南华早报）、Infosys、Sia Partners、WATI、Bosch、Intact Lab（香港）、Manulife、Taylor Root（对冲基金）等
  • 提取每份 JD 的「职责 + 任职要求 + 技术栈」→ 统计关键词出现频率 → 归一化为百分比
  • 薪酬为公开市场区间估算（jobsdb / talent.com / Glassdoor 与招聘机构公开数据），仅供参考
